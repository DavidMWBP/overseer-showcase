# Overseer v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Overseer v1: a local daemon plus web UI where one Claude Code orchestrator turns goals into beads tasks, dispatches headless workers into git worktrees, and the user reviews and lands the result.

**Architecture:** pnpm monorepo with three packages. `@overseer/daemon` (Node 22, Fastify, `node:sqlite`) owns all state and side effects: harness adapters, session manager, beads bridge, git worktrees, the lifecycle state machine, an MCP server for the orchestrator, and the REST + WebSocket API. `@overseer/web` (React + Vite) renders Chat, Board and Review over that API. `@overseer/shared` holds the API types both sides import.

**Tech Stack:** Node 22.14 (`node:sqlite` is built in from 22.13), pnpm 10 via corepack, TypeScript 5 (ESM, `moduleResolution: bundler`, run with `tsx`, no build step for the daemon), Fastify 5 + `@fastify/websocket`, zod 3, `@modelcontextprotocol/sdk` (Streamable HTTP transport), vitest 3, React 19 + Vite 6.

**Spec:** `docs/superpowers/specs/2026-09-12-overseer-design.md`

## Global Constraints

- Spec section 4.3 is binding: the daemon is the only writer of bead status and `overseer:*` labels. Workers never touch bead status. The worker prompt says so.
- Every `bd` invocation goes through `Beads.exec` (Task 4): per-repo serialized, `cwd` = the repo's primary checkout, `--json` appended. No other code path spawns `bd`. Beads runs Dolt embedded in-process as a single writer, so two concurrent `bd` processes on one repo can corrupt or fail; the queue is not optional.
- Branch name is `bead/<beadId>`. Worktree path is `<dataDir>/worktrees/<repoId>/<beadId>`. `dataDir` defaults to `~/.overseer`.
- REST routes live under `/api` (spec paths are relative to it). WebSocket at `/api/events`. Daemon port defaults to 4400.
- Sessions are long-lived processes with stdin input where the harness supports it (Claude Code: `--input-format stream-json`), and one process per turn where it does not (OpenCode, Codex). Either way a `turn_end` event marks a turn boundary and the adapter's `end()` closes the session. The session manager, not the adapter, decides when a worker session ends: after a `turn_end` with no queued messages.
- Every session starts in the harness's autonomous permission mode: Claude `--dangerously-skip-permissions`, OpenCode `--auto`, Codex `--full-auto`. The worktree is the isolation boundary.
- `HarnessEvent` gains one member beyond the spec's union: `{ type: 'process_start'; pid: number; pidStartedAt: string | null }`, emitted whenever an adapter spawns a process, so `sessions.pid` and `pid_started_at` stay current. Task 2 adds the line to the spec.
- Shell-outs use `child_process.spawn`/`execFile` directly. No `execa`, no `shelljs`.
- Tests run with `pnpm -r test` from the root. Every task's Verify line must pass before its commit.
- Spike results (2026-09-12, this machine): Claude Code 2.1.269 and OpenCode 1.18.19 are installed. `bd`, `codex`, `glab`, `pnpm` are not. Task 1 installs `pnpm` (corepack) and `bd` (npm). Codex and glab stay optional: their adapter and provider are built against documented contracts with fake binaries in tests, and CLAUDE.md lists them as unverified until the user installs them.

**User decisions (already made):**
- Orchestrator harness is Claude Code, hardcoded (spec section 1).
- Task store is beads via `bd --json`, never Dolt directly (spec 4.1).
- Only the user lands code in v1; the orchestrator can only `request_merge` (spec section 3).
- Sessions run in the harness's autonomous permission mode; the worktree is the isolation boundary (spec section 5, revised after review).
- `ask_user` is non-blocking: it posts a question, returns its id, and the orchestrator ends its turn (spec section 6).
- Task CRUD has no dedicated MCP tools; the orchestrator uses the `bd(repo, args)` passthrough (spec section 6).

export interface Config {
  port: number;
  dataDir: string;
  dbPath: string;
  worktreesDir: string;
  orchestratorDir: string;
  promptsDir: string;
  bdBin: string;
  claudeBin: string;
  codexBin: string;
  opencodeBin: string;
  glabBin: string;
}

export function loadConfig(env: NodeJS.ProcessEnv = process.env): Config {
  const dataDir = env.OVERSEER_DATA_DIR ?? path.join(os.homedir(), '.overseer');
  return {
    port: Number(env.OVERSEER_PORT ?? 4400),
    dataDir,
    dbPath: path.join(dataDir, 'overseer.db'),
    worktreesDir: path.join(dataDir, 'worktrees'),
    orchestratorDir: path.join(dataDir, 'orchestrator'),
    promptsDir: env.OVERSEER_PROMPTS_DIR ?? new URL('../prompts/', import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, '$1'),
    bdBin: env.OVERSEER_BD ?? 'bd',
    claudeBin: env.OVERSEER_CLAUDE ?? 'claude',
    codexBin: env.OVERSEER_CODEX ?? 'codex',
    opencodeBin: env.OVERSEER_OPENCODE ?? 'opencode',
    glabBin: env.OVERSEER_GLAB ?? 'glab',
  };
}

```ts
export class EventQueue<T> implements AsyncIterable<T> {
  private items: T[] = [];
  private waiters: ((r: IteratorResult<T>) => void)[] = [];
  private closed = false;

  push(item: T): void {
    if (this.closed) return;
    const w = this.waiters.shift();
    if (w) w({ value: item, done: false }); else this.items.push(item);
  }

  close(): void {
    this.closed = true;
    for (const w of this.waiters.splice(0)) w({ value: undefined as never, done: true });
  }

  [Symbol.asyncIterator](): AsyncIterator<T> {
    return {
      next: () => {
        const item = this.items.shift();
        if (item !== undefined) return Promise.resolve({ value: item, done: false });
        if (this.closed) return Promise.resolve({ value: undefined as never, done: true });
        return new Promise((resolve) => this.waiters.push(resolve));
      },
    };
  }
}

import { spawn, execFile, type ChildProcess } from 'node:child_process';
import { createInterface } from 'node:readline';
import { EventQueue } from './queue';

export interface LineProcess {
  child: ChildProcess;
  lines: AsyncIterable<string>;
  exit: Promise<number>;
}

export function spawnLines(cmd: string, args: string[], opts: { cwd?: string; env?: NodeJS.ProcessEnv } = {}): LineProcess {
  const child = spawn(cmd, args, { cwd: opts.cwd, env: { ...process.env, ...opts.env }, stdio: ['pipe', 'pipe', 'pipe'], shell: process.platform === 'win32' });
  const q = new EventQueue<string>();
  const rl = createInterface({ input: child.stdout! });
  rl.on('line', (l) => q.push(l));
  let stderr = '';
  child.stderr!.on('data', (d) => { stderr += String(d); });
  const exit = new Promise<number>((resolve) => {
    child.on('close', (code) => { rl.close(); q.close(); resolve(code ?? -1); });
    child.on('error', () => { q.close(); resolve(-1); });
  });
  (exit as Promise<number> & { stderr?: () => string });
  return { child, lines: q, exit: exit.then((c) => { (child as ChildProcess & { stderrText?: string }).stderrText = stderr; return c; }) };
}

function run(cmd: string, args: string[]): Promise<string> {
  return new Promise((resolve) => execFile(cmd, args, { windowsHide: true }, (_e, out) => resolve(String(out ?? '').trim())));
}

export async function processStartTime(pid: number): Promise<string | null> {
  if (process.platform === 'win32') {
    const out = await run('powershell', ['-NoProfile', '-Command', `(Get-Process -Id ${pid} -ErrorAction SilentlyContinue).StartTime.ToString('o')`]);
    return out || null;
  }
  const out = await run('ps', ['-o', 'lstart=', '-p', String(pid)]);
  return out || null;
}

export async function isAlive(pid: number, startedAt: string | null): Promise<boolean> {
  const now = await processStartTime(pid);
  if (!now) return false;
  return startedAt === null ? true : now === startedAt;
}

export async function killProcess(pid: number): Promise<void> {
  if (process.platform === 'win32') { await run('taskkill', ['/PID', String(pid), '/T', '/F']); return; }
  try { process.kill(pid, 'SIGTERM'); } catch { /* already gone */ }
}

import { DatabaseSync } from 'node:sqlite';
import fs from 'node:fs';
import path from 'node:path';
import type { ChatRow, EventRow, Repo, SessionRole, SessionRow, WorktreeRow } from '@overseer/shared';
import { SCHEMA } from './schema';

const now = () => new Date().toISOString();

type Row = Record<string, unknown>;

export class Db {
  constructor(readonly sql: DatabaseSync) {}

  repos = {
    insert: (r: Repo) => this.sql.prepare('INSERT INTO repos VALUES (?,?,?,?,?,?)').run(r.id, r.path, r.base_branch, r.verify_command, r.merge_mode, r.worker_limit),
    get: (id: string) => this.sql.prepare('SELECT * FROM repos WHERE id=?').get(id) as Repo | undefined,
    all: () => this.sql.prepare('SELECT * FROM repos ORDER BY id').all() as unknown as Repo[],
  };

  sessions = {
    insert: (s: SessionRow) => this.sql.prepare('INSERT INTO sessions VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?)').run(s.id, s.harness, s.role, s.bead_id, s.repo_id, s.native_session_id, s.pid, s.pid_started_at, s.start_commit, s.cwd, s.status, s.started_at, s.ended_at, s.cost),
    update: (id: string, patch: Partial<SessionRow>) => this.patch('sessions', 'id', id, patch),
    get: (id: string) => this.sql.prepare('SELECT * FROM sessions WHERE id=?').get(id) as SessionRow | undefined,
    running: () => this.sql.prepare("SELECT * FROM sessions WHERE status='running'").all() as unknown as SessionRow[],
    forBead: (beadId: string) => this.sql.prepare('SELECT * FROM sessions WHERE bead_id=? ORDER BY started_at').all(beadId) as unknown as SessionRow[],
    runningWorkersForRepo: (repoId: string) => this.sql.prepare("SELECT * FROM sessions WHERE repo_id=? AND role='worker' AND status='running'").all(repoId) as unknown as SessionRow[],
    latest: (role: SessionRole) => this.sql.prepare('SELECT * FROM sessions WHERE role=? ORDER BY started_at DESC LIMIT 1').get(role) as SessionRow | undefined,
  };

  worktrees = {
    upsert: (w: WorktreeRow) => this.sql.prepare('INSERT OR REPLACE INTO worktrees VALUES (?,?,?,?,?,?,?,?,?,?,?)').run(w.bead_id, w.repo_id, w.path, w.branch, w.base_branch, w.verify_status, w.verify_output, w.review_note, w.conflict_files ? JSON.stringify(w.conflict_files) : null, w.merged_at, w.mr_url),
    update: (beadId: string, patch: Partial<WorktreeRow>) => this.patch('worktrees', 'bead_id', beadId, { ...patch, ...(patch.conflict_files !== undefined ? { conflict_files: patch.conflict_files ? JSON.stringify(patch.conflict_files) : null } : {}) } as Row),
    get: (beadId: string) => this.parseWt(this.sql.prepare('SELECT * FROM worktrees WHERE bead_id=?').get(beadId) as Row | undefined),
    forRepo: (repoId: string) => (this.sql.prepare('SELECT * FROM worktrees WHERE repo_id=?').all(repoId) as Row[]).map((r) => this.parseWt(r)!),
    delete: (beadId: string) => this.sql.prepare('DELETE FROM worktrees WHERE bead_id=?').run(beadId),
  };

  events = {
    append: (sessionId: string, type: string, payload: unknown): EventRow => {
      const seq = (this.sql.prepare('SELECT COALESCE(MAX(seq),0)+1 AS n FROM events WHERE session_id=?').get(sessionId) as { n: number }).n;
      const ts = now();
      const r = this.sql.prepare('INSERT INTO events (session_id,seq,type,payload,ts) VALUES (?,?,?,?,?)').run(sessionId, seq, type, JSON.stringify(payload ?? null), ts);
      return { id: Number(r.lastInsertRowid), session_id: sessionId, seq, type, payload, ts };
    },
    forSession: (sessionId: string) => (this.sql.prepare('SELECT * FROM events WHERE session_id=? ORDER BY seq').all(sessionId) as Row[]).map(parseEvent),
    lastOfType: (sessionId: string, type: string) => { const r = this.sql.prepare('SELECT * FROM events WHERE session_id=? AND type=? ORDER BY seq DESC LIMIT 1').get(sessionId, type) as Row | undefined; return r ? parseEvent(r) : undefined; },
  };

  chat = {
    insert: (c: { role: ChatRow['role']; kind: ChatRow['kind']; text: string }): ChatRow => {
      const ts = now();
      const r = this.sql.prepare('INSERT INTO chat (role,kind,text,ts) VALUES (?,?,?,?)').run(c.role, c.kind, c.text, ts);
      return { id: Number(r.lastInsertRowid), ...c, ts, answer: null, answered_at: null };
    },
    all: () => this.sql.prepare('SELECT * FROM chat ORDER BY id').all() as unknown as ChatRow[],
    get: (id: number) => this.sql.prepare('SELECT * FROM chat WHERE id=?').get(id) as ChatRow | undefined,
    pendingQuestions: () => this.sql.prepare("SELECT * FROM chat WHERE kind='question' AND answered_at IS NULL ORDER BY id").all() as unknown as ChatRow[],
    answer: (id: number, answer: string) => this.sql.prepare('UPDATE chat SET answer=?, answered_at=? WHERE id=?').run(answer, now(), id),
  };

  private patch(table: string, key: string, id: string, patch: Row) {
    const cols = Object.keys(patch);
    if (cols.length === 0) return;
    this.sql.prepare(`UPDATE ${table} SET ${cols.map((c) => `${c}=?`).join(', ')} WHERE ${key}=?`).run(...cols.map((c) => patch[c] as never), id);
  }

  private parseWt(r: Row | undefined): WorktreeRow | undefined {
    if (!r) return undefined;
    return { ...(r as unknown as WorktreeRow), conflict_files: r.conflict_files ? JSON.parse(String(r.conflict_files)) : null };
  }
}

function parseEvent(r: Row): EventRow {
  return { ...(r as unknown as EventRow), payload: JSON.parse(String(r.payload)) };
}

export function openDb(file: string): Db {
  if (file !== ':memory:') fs.mkdirSync(path.dirname(file), { recursive: true });
  const sql = new DatabaseSync(file);
  sql.exec('PRAGMA journal_mode=WAL; PRAGMA foreign_keys=ON;');
  sql.exec(SCHEMA);
  return new Db(sql);
}

  return (cwd, args) => runCapture(bin, args, { cwd });

export function parseBead(raw: Record<string, unknown>): Bead {
  const labelsRaw = Array.isArray(raw.labels) ? raw.labels : [];
  const labels = labelsRaw.map((l) => (typeof l === 'string' ? l : String((l as { label?: string; name?: string }).label ?? (l as { name?: string }).name ?? ''))).filter(Boolean);
  return {
    id: String(raw.id),
    title: String(raw.title ?? ''),
    description: String(raw.description ?? ''),
    status: (raw.status as Bead['status']) ?? 'open',
    priority: Number(raw.priority ?? 2),
    labels,
    notes: String(raw.notes ?? ''),
    assignee: raw.assignee ? String(raw.assignee) : null,
  };
}

const STATUSES = ['open', 'in_progress', 'blocked', 'closed'] as const;

export class Beads implements TaskStore {
  private tails = new Map<string, Promise<unknown>>();
  constructor(private run: BdRunner) {}

  async available(): Promise<boolean> {
    try { return (await this.run('.', ['--version'])).code === 0; } catch { return false; }
  }

  async exec(repoPath: string, args: string[]): Promise<unknown> {
    const prev = this.tails.get(repoPath) ?? Promise.resolve();
    const job = async () => {
      const r = await this.run(repoPath, [...args, '--json']);
      if (r.code !== 0) throw new BdError(args, r.stderr || r.stdout);
      const text = r.stdout.trim();
      if (!text) return null;
      try { return JSON.parse(text); } catch { return text; }
    };
    const next = prev.then(job, job);
    this.tails.set(repoPath, next.catch(() => undefined));
    return next;
  }

  async list(repoPath: string): Promise<Bead[]> {
    const out: Bead[] = [];
    for (const s of STATUSES) {
      const rows = (await this.exec(repoPath, ['list', '--status', s])) as unknown[] | null;
      for (const r of rows ?? []) out.push(parseBead(r as Record<string, unknown>));
    }
    return out;
  }

  async ready(repoPath: string): Promise<string[]> {
    const rows = (await this.exec(repoPath, ['ready'])) as { id: string }[] | null;
    return (rows ?? []).map((r) => r.id);
  }

  async show(repoPath: string, id: string): Promise<Bead | null> {
    try {
      const r = (await this.exec(repoPath, ['show', id])) as Record<string, unknown> | Record<string, unknown>[] | null;
      const one = Array.isArray(r) ? r[0] : r;
      return one ? parseBead(one) : null;
    } catch (e) {
      if (e instanceof BdError && /not found/i.test(e.message)) return null;
      throw e;
    }
  }

  async setStatus(repoPath: string, id: string, status: 'open' | 'in_progress'): Promise<void> {
    await this.exec(repoPath, ['update', id, '--status', status]);
  }

  async setPhase(repoPath: string, id: string, phase: Phase | null): Promise<void> {
    const bead = await this.show(repoPath, id);
    for (const l of bead?.labels ?? []) if (l.startsWith(PHASE_PREFIX)) await this.exec(repoPath, ['label', 'remove', id, l]);
    if (phase) await this.exec(repoPath, ['label', 'add', id, `${PHASE_PREFIX}${phase}`]);
  }

  async appendNote(repoPath: string, id: string, note: string): Promise<void> {
    await this.exec(repoPath, ['update', id, '--append-notes', note]);
  }

  async close(repoPath: string, id: string, reason: string): Promise<void> {
    await this.exec(repoPath, ['close', id, '--reason', reason]);
  }

  raw(repoPath: string, args: string[]): Promise<unknown> {
    return this.exec(repoPath, args.filter((a) => a !== '--json'));
  }
}

import type { Bead, Phase } from '@overseer/shared';
import { PHASE_PREFIX, type TaskStore } from './store';

export class MemoryTaskStore implements TaskStore {
  private repos = new Map<string, Map<string, Bead & { deps: string[] }>>();
  unavailable = false;

  add(repoPath: string, bead: Partial<Bead> & { id: string }, deps: string[] = []): Bead {
    const full = { title: bead.id, description: '', status: 'open' as const, priority: 2, labels: [], notes: '', assignee: null, ...bead, deps };
    this.repo(repoPath).set(bead.id, full);
    return full;
  }
  async available() { return !this.unavailable; }
  async list(repoPath: string) { return [...this.repo(repoPath).values()].map(strip); }
  async ready(repoPath: string) {
    const all = this.repo(repoPath);
    return [...all.values()].filter((b) => b.status === 'open' && b.deps.every((d) => all.get(d)?.status === 'closed')).map((b) => b.id);
  }
  async show(repoPath: string, id: string) { const b = this.repo(repoPath).get(id); return b ? strip(b) : null; }
  async setStatus(repoPath: string, id: string, status: 'open' | 'in_progress') { this.must(repoPath, id).status = status; }
  async setPhase(repoPath: string, id: string, phase: Phase | null) {
    const b = this.must(repoPath, id);
    b.labels = b.labels.filter((l) => !l.startsWith(PHASE_PREFIX));
    if (phase) b.labels.push(`${PHASE_PREFIX}${phase}`);
  }
  async appendNote(repoPath: string, id: string, note: string) { const b = this.must(repoPath, id); b.notes = b.notes ? `${b.notes}\n${note}` : note; }
  async close(repoPath: string, id: string, reason: string) { const b = this.must(repoPath, id); b.status = 'closed'; b.notes += `\nclosed: ${reason}`; }
  async raw(): Promise<unknown> { throw new Error('raw bd is not supported by MemoryTaskStore'); }

  private repo(p: string) { let r = this.repos.get(p); if (!r) { r = new Map(); this.repos.set(p, r); } return r; }
  private must(p: string, id: string) { const b = this.repo(p).get(id); if (!b) throw new Error(`bead ${id} not found`); return b; }
}

import { execFile } from 'node:child_process';
import fs from 'node:fs';
import path from 'node:path';
import type { Repo } from '@overseer/shared';

export class GitError extends Error {
  constructor(message: string, readonly stderr: string) { super(message); }
}

export function git(cwd: string, args: string[]): Promise<string> {
  return new Promise((resolve, reject) => {
    execFile('git', args, { cwd, windowsHide: true, maxBuffer: 64 * 1024 * 1024 }, (err, stdout, stderr) => {
      if (err) reject(new GitError(`git ${args.join(' ')} failed: ${String(stderr || err.message).trim()}`, String(stderr)));
      else resolve(String(stdout).trim());
    });
  });
}

export const branchFor = (beadId: string) => `bead/${beadId}`;
export const worktreePath = (worktreesDir: string, repoId: string, beadId: string) => path.join(worktreesDir, repoId, beadId);

export async function ensureWorktree(repo: Repo, beadId: string, worktreesDir: string): Promise<{ path: string; branch: string; created: boolean }> {
  const wt = worktreePath(worktreesDir, repo.id, beadId);
  const branch = branchFor(beadId);
  await git(repo.path, ['worktree', 'prune']);
  if (fs.existsSync(wt)) {
    await git(wt, ['rev-parse', '--is-inside-work-tree']);
    return { path: wt, branch, created: false };
  }
  fs.mkdirSync(path.dirname(wt), { recursive: true });
  const exists = await git(repo.path, ['branch', '--list', branch]);
  if (exists) await git(repo.path, ['worktree', 'add', wt, branch]);
  else await git(repo.path, ['worktree', 'add', '-b', branch, wt, repo.base_branch]);
  return { path: wt, branch, created: true };
}

export const headCommit = (cwd: string) => git(cwd, ['rev-parse', 'HEAD']);

export async function commitsSince(cwd: string, since: string): Promise<number> {
  return Number(await git(cwd, ['rev-list', '--count', `${since}..HEAD`]));
}

export const diffAgainstBase = (cwd: string, base: string) => git(cwd, ['diff', `${base}...HEAD`]);

export async function changedFiles(cwd: string, base: string): Promise<string[]> {
  return (await git(cwd, ['diff', '--name-only', `${base}...HEAD`])).split('\n').filter(Boolean);
}

export async function removeWorktree(repoPath: string, wtPath: string, branch: string): Promise<void> {
  if (fs.existsSync(wtPath)) await git(repoPath, ['worktree', 'remove', '--force', wtPath]);
  await git(repoPath, ['worktree', 'prune']);
  if (await git(repoPath, ['branch', '--list', branch])) await git(repoPath, ['branch', '-D', branch]);
}

export async function mergeLocal(repoPath: string, branch: string, base: string, message: string): Promise<{ ok: true } | { ok: false; conflicts: string[] }> {
  const current = await git(repoPath, ['rev-parse', '--abbrev-ref', 'HEAD']);
  if (current !== base) throw new GitError(`primary checkout is on ${current}, expected ${base}`, '');
  if (await git(repoPath, ['status', '--porcelain'])) throw new GitError('primary checkout has uncommitted changes', '');
  try {
    await git(repoPath, ['merge', '--no-ff', '-m', message, branch]);
    return { ok: true };
  } catch (e) {
    const conflicts = (await git(repoPath, ['diff', '--name-only', '--diff-filter=U'])).split('\n').filter(Boolean);
    await git(repoPath, ['merge', '--abort']).catch(() => undefined);
    if (conflicts.length) return { ok: false, conflicts };
    throw e;
  }
}

export const pushBranch = (cwd: string, branch: string) => git(cwd, ['push', '-u', 'origin', branch]);

```ts
import { randomUUID } from 'node:crypto';
import type { HarnessName, SessionRole, SessionRow } from '@overseer/shared';
import type { Db } from '../db/db';
import type { Bus, SessionEnded } from '../bus';
import type { HarnessAdapter, McpServerConfig, SessionHandle } from '../harness/types';

export type { SessionEnded };

export interface StartSessionOpts {
  role: SessionRole;
  harness: HarnessName;
  repoId?: string | null;
  beadId?: string | null;
  cwd: string;
  prompt: string;
  systemPromptFile?: string;
  mcpServers?: McpServerConfig[];
  resumeId?: string;
  startCommit?: string | null;
  keepAlive?: boolean;
}

interface Live {
  adapter: HarnessAdapter;
  handle: SessionHandle;
  keepAlive: boolean;
  queued: number;
  lastText: string | null;
  lastError: string | null;
  errorSinceTurn: boolean;
  files: Set<string>;
  cost: number | null;
}

export class SessionManager {
  private live = new Map<string, Live>();

  constructor(private db: Db, private adapters: Partial<Record<HarnessName, HarnessAdapter>>, private bus: Bus) {}

  start(o: StartSessionOpts): SessionRow {
    const adapter = this.adapters[o.harness];
    if (!adapter) throw new Error(`harness ${o.harness} is not available`);
    const row: SessionRow = {
      id: randomUUID(), harness: o.harness, role: o.role, bead_id: o.beadId ?? null, repo_id: o.repoId ?? null,
      native_session_id: o.resumeId ?? null, pid: null, pid_started_at: null, start_commit: o.startCommit ?? null,
      cwd: o.cwd, status: 'running', started_at: new Date().toISOString(), ended_at: null, cost: null,
    };
    this.db.sessions.insert(row);
    const handle = adapter.start({ cwd: o.cwd, prompt: o.prompt, systemPromptFile: o.systemPromptFile, mcpServers: o.mcpServers, resumeId: o.resumeId });
    const live: Live = { adapter, handle, keepAlive: !!o.keepAlive, queued: 0, lastText: null, lastError: null, errorSinceTurn: false, files: new Set(), cost: null };
    this.live.set(row.id, live);
    void this.consume(row.id, live);
    this.bus.emit('board');
    return row;
  }

  handleOf(id: string): SessionHandle | undefined { return this.live.get(id)?.handle; }
  isLive(id: string): boolean { return this.live.has(id); }

  async send(id: string, text: string): Promise<void> {
    const l = this.must(id);
    l.queued++;
    await l.adapter.send(l.handle, text);
  }

  async interrupt(id: string): Promise<void> {
    const l = this.must(id);
    await l.adapter.interrupt(l.handle);
    await l.adapter.end(l.handle);
  }

  async end(id: string): Promise<void> { const l = this.live.get(id); if (l) await l.adapter.end(l.handle); }

  status(id: string): { state: SessionRow['status']; lastText: string | null; files: string[]; cost: number | null } {
    const row = this.db.sessions.get(id);
    if (!row) throw new Error(`session ${id} not found`);
    const l = this.live.get(id);
    const lastText = l?.lastText ?? (this.db.events.lastOfType(id, 'assistant_text')?.payload as { text?: string } | undefined)?.text ?? null;
    const files = l ? [...l.files] : [...new Set(this.db.events.forSession(id).filter((e) => e.type === 'file_change').map((e) => (e.payload as { path: string }).path))];
    return { state: row.status, lastText, files, cost: row.cost };
  }

  private async consume(id: string, l: Live): Promise<void> {
    for await (const ev of l.adapter.events(l.handle)) {
      this.bus.emit('event', this.db.events.append(id, ev.type, ev));
      switch (ev.type) {
        case 'process_start': this.db.sessions.update(id, { pid: ev.pid, pid_started_at: ev.pidStartedAt }); break;
        case 'assistant_text': l.lastText = ev.text; break;
        case 'file_change': l.files.add(ev.path); break;
        case 'error': l.lastError = ev.message; l.errorSinceTurn = true; break;
        case 'turn_end': {
          l.errorSinceTurn = false;
          if (ev.cost !== undefined) l.cost = ev.cost;
          this.db.sessions.update(id, { native_session_id: ev.nativeSessionId, cost: l.cost });
          if (!l.keepAlive) { if (l.queued > 0) l.queued--; else await l.adapter.end(l.handle); }
          break;
        }
        default: break;
      }
    }
    const status = l.errorSinceTurn ? 'failed' : 'ended';
    this.db.sessions.update(id, { status, ended_at: new Date().toISOString(), pid: null });
    this.live.delete(id);
    const session = this.db.sessions.get(id)!;
    this.bus.emit('session:ended', { session, lastText: l.lastText, lastError: l.lastError, files: [...l.files] });
    this.bus.emit('board');
  }

  private must(id: string): Live {
    const l = this.live.get(id);
    if (!l) throw new Error(`session ${id} is not running`);
    return l;
  }
}

import { spawn } from 'node:child_process';

export interface VerifyResult { status: 'pass' | 'fail'; output: string }

export function runVerify(command: string | null, cwd: string, timeoutMs = 20 * 60_000): Promise<VerifyResult> {
  if (!command) return Promise.resolve({ status: 'pass', output: '(no verify command configured)' });
  return new Promise((resolve) => {
    const child = spawn(command, { cwd, shell: true, windowsHide: true });
    let out = '';
    let timedOut = false;
    const cap = (d: Buffer) => { out += String(d); if (out.length > 200_000) out = out.slice(-200_000); };
    child.stdout.on('data', cap);
    child.stderr.on('data', cap);
    const timer = setTimeout(() => { timedOut = true; child.kill(); }, timeoutMs);
    child.on('close', (code) => {
      clearTimeout(timer);
      const tail = timedOut ? '\n(timed out)' : `\nexit ${code}`;
      resolve({ status: code === 0 && !timedOut ? 'pass' : 'fail', output: `$ ${command}\n${out}${tail}` });
    });
    child.on('error', (e) => { clearTimeout(timer); resolve({ status: 'fail', output: `$ ${command}\n${String(e)}` }); });
  });
}

```ts
import fs from 'node:fs';
import path from 'node:path';
import type { HarnessName, Repo, WorktreeRow } from '@overseer/shared';
import type { Db } from '../db/db';
import type { Bus, SessionEnded } from '../bus';
import type { Config } from '../config';
import type { TaskStore } from '../beads/store';
import { phaseOf } from '../beads/store';
import type { SessionManager } from '../sessions/manager';
import { ensureWorktree, headCommit, commitsSince, removeWorktree } from '../git/git';
import { MergeConflictError, type GitProvider } from '../git/provider';
import { isAlive, killProcess } from '../util/procs';
import { buildWorkerPrompt } from './prompt';
import { runVerify } from './verify';

export class LifecycleError extends Error {}

export interface LifecycleDeps {
  db: Db;
  store: TaskStore;
  sessions: SessionManager;
  bus: Bus;
  config: Config;
  provider: (repo: Repo) => GitProvider;
  notify: (text: string) => Promise<void>;
}

export class Lifecycle {
  private workerTemplate: string;

  constructor(private d: LifecycleDeps) {
    this.workerTemplate = fs.readFileSync(path.join(d.config.promptsDir, 'worker.md'), 'utf8');
    d.bus.on('session:ended', (e) => {
      if (e.session.role === 'worker') void this.onWorkerEnded(e).catch((err) => console.error('lifecycle: session end handling failed', err));
    });
  }

  async spawnWorker(repoId: string, beadId: string, harness: HarnessName, instructions?: string): Promise<string> {
    const { db, store, sessions, config } = this.d;
    if (!(await store.available())) throw new LifecycleError('bd is not available');
    const repo = db.repos.get(repoId);
    if (!repo) throw new LifecycleError(`repo ${repoId} not found`);
    const bead = await store.show(repo.path, beadId);
    if (!bead) throw new LifecycleError(`bead ${beadId} not found in ${repoId}`);
    if (bead.status === 'closed') throw new LifecycleError(`bead ${beadId} is closed`);
    if (db.sessions.forBead(beadId).some((s) => s.status === 'running')) throw new LifecycleError(`bead ${beadId} already has a running session`);
    if (db.sessions.runningWorkersForRepo(repoId).length >= repo.worker_limit) throw new LifecycleError(`worker limit ${repo.worker_limit} reached for ${repoId}`);

    const wt = await ensureWorktree(repo, beadId, config.worktreesDir);
    const existing = db.worktrees.get(beadId);
    const conflicts = existing?.conflict_files ?? [];
    db.worktrees.upsert({ bead_id: beadId, repo_id: repoId, path: wt.path, branch: wt.branch, base_branch: repo.base_branch, verify_status: null, verify_output: null, review_note: null, conflict_files: existing?.conflict_files ?? null, merged_at: null, mr_url: null });
    const prompt = buildWorkerPrompt(this.workerTemplate, { bead, branch: wt.branch, base: repo.base_branch, conflicts, instructions });
    await store.setStatus(repo.path, beadId, 'in_progress');
    await store.setPhase(repo.path, beadId, null);
    const startCommit = await headCommit(wt.path);
    const session = sessions.start({ role: 'worker', harness, repoId, beadId, cwd: wt.path, prompt, startCommit });
    this.d.bus.emit('board');
    return session.id;
  }

  private async onWorkerEnded(e: SessionEnded): Promise<void> {
    const { db, store } = this.d;
    const { session } = e;
    const repo = session.repo_id ? db.repos.get(session.repo_id) : undefined;
    const wt = session.bead_id ? db.worktrees.get(session.bead_id) : undefined;
    if (!repo || !wt || !session.bead_id) return;
    const commits = session.start_commit ? await commitsSince(wt.path, session.start_commit) : 0;
    if (commits === 0) {
      db.sessions.update(session.id, { status: 'failed' });
      await store.setStatus(repo.path, session.bead_id, 'open');
      await store.setPhase(repo.path, session.bead_id, null);
      await store.appendNote(repo.path, session.bead_id, `Worker session ${session.id} ended without new commits: ${e.lastError ?? e.lastText ?? 'no output'}`);
    } else {
      await this.verify(repo, wt, session.bead_id);
    }
    this.d.bus.emit('board');
  }

  private async verify(repo: Repo, wt: WorktreeRow, beadId: string): Promise<void> {
    const { db, store, bus } = this.d;
    await store.setPhase(repo.path, beadId, 'verifying');
    bus.emit('board');
    const r = await runVerify(repo.verify_command, wt.path);
    db.worktrees.update(beadId, { verify_status: r.status, verify_output: r.output, conflict_files: null });
    await store.setPhase(repo.path, beadId, 'review');
  }

  async requestMerge(repoId: string, beadId: string, note: string): Promise<void> {
    const wt = this.d.db.worktrees.get(beadId);
    if (!wt || wt.repo_id !== repoId) throw new LifecycleError(`no worktree for ${beadId} in ${repoId}`);
    if (wt.verify_status !== 'pass') throw new LifecycleError(`verification has not passed for ${beadId} (status: ${wt.verify_status ?? 'not run'})`);
    this.d.db.worktrees.update(beadId, { review_note: note });
    this.d.bus.emit('board');
  }

  async merge(beadId: string): Promise<{ mrUrl?: string }> {
    const { db, store, bus, notify } = this.d;
    const wt = db.worktrees.get(beadId);
    if (!wt) throw new LifecycleError(`no worktree for ${beadId}`);
    const repo = db.repos.get(wt.repo_id)!;
    const bead = await store.show(repo.path, beadId);
    if (!bead) throw new LifecycleError(`bead ${beadId} not found`);
    if (phaseOf(bead) !== 'review') throw new LifecycleError(`${beadId} is not in review`);
    const description = wt.review_note ?? `${bead.title}\n\n${bead.description}`;
    const r = await this.d.provider(repo).land(repo, wt, { title: bead.title, description });
    if (!r.ok) {
      db.worktrees.update(beadId, { conflict_files: r.conflicts });
      await notify(`Merge of ${beadId} into ${repo.base_branch} conflicted in: ${r.conflicts.join(', ')}. Reject it with a note and re-dispatch with spawn_worker to rebase; the worker prompt will list the files.`);
      bus.emit('board');
      throw new MergeConflictError(r.conflicts);
    }
    await store.close(repo.path, beadId, 'merged by Overseer');
    await store.setPhase(repo.path, beadId, 'merged');
    db.worktrees.update(beadId, { merged_at: new Date().toISOString(), mr_url: r.mrUrl ?? null });
    await removeWorktree(repo.path, wt.path, wt.branch);
    bus.emit('board');
    return { mrUrl: r.mrUrl };
  }

  async reject(beadId: string, note: string): Promise<void> {
    const { db, store, bus } = this.d;
    const wt = db.worktrees.get(beadId);
    if (!wt) throw new LifecycleError(`no worktree for ${beadId}`);
    const repo = db.repos.get(wt.repo_id)!;
    const bead = await store.show(repo.path, beadId);
    if (!bead || phaseOf(bead) !== 'review') throw new LifecycleError(`${beadId} is not in review`);
    await store.setStatus(repo.path, beadId, 'open');
    await store.setPhase(repo.path, beadId, 'rejected');
    await store.appendNote(repo.path, beadId, `Rejected: ${note}`);
    db.worktrees.update(beadId, { review_note: null });
    bus.emit('board');
  }

  async recover(): Promise<void> {
    const { db } = this.d;
    for (const s of db.sessions.running()) {
      if (s.pid && (await isAlive(s.pid, s.pid_started_at))) await killProcess(s.pid);
      db.sessions.update(s.id, { status: 'ended', ended_at: new Date().toISOString(), pid: null });
      if (s.role === 'worker') await this.onWorkerEnded({ session: db.sessions.get(s.id)!, lastText: null, lastError: 'daemon restarted while the worker was running', files: [] });
    }
    this.d.bus.emit('board');
  }
}

import { randomUUID } from 'node:crypto';
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { EventQueue } from '../util/queue';
import { spawnLines, processStartTime, killProcess, quoteArg, type LineProcess } from '../util/procs';
import type { HarnessAdapter, HarnessEvent, SessionHandle, StartOpts } from './types';

const FILE_TOOLS = new Set(['Edit', 'Write', 'MultiEdit', 'NotebookEdit']);

export function parseClaudeLine(line: string): HarnessEvent[] {
  let msg: Record<string, unknown>;
  try { msg = JSON.parse(line); } catch { return [{ type: 'raw', line }]; }
  const parentId = typeof msg.parent_tool_use_id === 'string' ? msg.parent_tool_use_id : undefined;
  const content = ((msg.message as { content?: unknown[] } | undefined)?.content ?? []) as Record<string, unknown>[];
  switch (msg.type) {
    case 'assistant': {
      const out: HarnessEvent[] = [];
      for (const c of content) {
        if (c.type === 'text' && typeof c.text === 'string' && c.text) out.push({ type: 'assistant_text', text: c.text });
        if (c.type === 'tool_use') {
          out.push({ type: 'tool_call', id: String(c.id), name: String(c.name), input: c.input, parentId });
          const input = (c.input ?? {}) as { file_path?: string; notebook_path?: string };
          const p = FILE_TOOLS.has(String(c.name)) ? input.file_path ?? input.notebook_path : undefined;
          if (p) out.push({ type: 'file_change', path: p });
        }
      }
      return out;
    }
    case 'user':
      return content.filter((c) => c.type === 'tool_result').map((c) => ({ type: 'tool_result', id: String(c.tool_use_id), output: c.content }));
    case 'result': {
      const out: HarnessEvent[] = [];
      if (msg.is_error) out.push({ type: 'error', message: String(msg.result ?? msg.subtype ?? 'error') });
      out.push({ type: 'turn_end', nativeSessionId: String(msg.session_id ?? ''), cost: typeof msg.total_cost_usd === 'number' ? msg.total_cost_usd : undefined });
      return out;
    }
    case 'system':
    case 'stream_event':
      return [];
    default:
      return [{ type: 'raw', line }];
  }
}

export function claudeArgs(o: StartOpts, nativeId: string, resume: boolean, mcpConfigFile: string | null): string[] {
  const args = ['-p', '--output-format', 'stream-json', '--input-format', 'stream-json', '--verbose', '--dangerously-skip-permissions'];
  args.push(...(resume ? ['--resume', nativeId] : ['--session-id', nativeId]));
  if (o.systemPromptFile) args.push('--append-system-prompt-file', o.systemPromptFile);
  if (mcpConfigFile) args.push('--mcp-config', mcpConfigFile, '--strict-mcp-config');
  return args;
}

class ClaudeSession {
  readonly queue = new EventQueue<HarnessEvent>();
  private proc: LineProcess | null = null;
  private ending = false;
  private mcpConfigFile: string | null = null;

  constructor(private bin: string, private opts: StartOpts, readonly nativeId: string, private resume: boolean) {
    if (opts.mcpServers?.length) {
      this.mcpConfigFile = path.join(os.tmpdir(), `overseer-mcp-${nativeId}.json`);
      fs.writeFileSync(this.mcpConfigFile, JSON.stringify({ mcpServers: Object.fromEntries(opts.mcpServers.map((m) => [m.name, { type: 'http', url: m.url }])) }));
    }
  }

  write(text: string): void {
    if (!this.proc) this.spawn();
    this.proc!.child.stdin!.write(JSON.stringify({ type: 'user', message: { role: 'user', content: [{ type: 'text', text }] } }) + '\n');
  }

  private spawn(): void {
    const args = claudeArgs(this.opts, this.nativeId, this.resume, this.mcpConfigFile);
    const p = spawnLines(this.bin, process.platform === 'win32' ? args.map(quoteArg) : args, { cwd: this.opts.cwd });
    this.proc = p;
    this.resume = true;
    void this.pump(p);
  }

  private async pump(p: LineProcess): Promise<void> {
    const pid = p.child.pid;
    if (pid) this.queue.push({ type: 'process_start', pid, pidStartedAt: await processStartTime(pid) });
    for await (const line of p.lines) for (const ev of parseClaudeLine(line)) this.queue.push(ev);
    const code = await p.exit;
    if (this.proc === p) this.proc = null;
    if (code !== 0 && !this.ending) this.queue.push({ type: 'error', message: `claude exited with code ${code}` });
    if (this.ending) this.queue.close();
  }

  async end(): Promise<void> {
    this.ending = true;
    const p = this.proc;
    if (!p) { this.queue.close(); return; }
    p.child.stdin!.end();
    const timer = setTimeout(() => { if (p.child.pid) void killProcess(p.child.pid); }, 10_000);
    await p.exit;
    clearTimeout(timer);
  }

  async interrupt(): Promise<void> {
    const pid = this.proc?.child.pid;
    if (pid) await killProcess(pid);
  }
}

export class ClaudeAdapter implements HarnessAdapter {
  readonly name = 'claude' as const;
  private sessions = new Map<string, ClaudeSession>();

    const s = this.sessions.get(h.id);
    if (!s) throw new Error(`claude session ${h.id} not found`);
    return s;
  }

import { randomUUID } from 'node:crypto';
import { EventQueue } from '../util/queue';
import { spawnLines, processStartTime, killProcess, quoteArg, type LineProcess } from '../util/procs';
import type { HarnessAdapter, HarnessEvent, SessionHandle, StartOpts } from './types';

const FILE_TOOLS = new Set(['edit', 'write', 'multiedit', 'patch']);

export function opencodeArgs(cwd: string, sessionId: string | null, prompt: string): string[] {
  const args = ['run', '--format', 'json', '--auto', '--dir', cwd];
  if (sessionId) args.push('--session', sessionId);
  args.push(prompt);
  return args;
}

type Part = { type?: string; text?: string; tool?: string; callID?: string; cost?: number; state?: { status?: string; input?: unknown; output?: unknown } };

export class OpencodeParser {
  sessionId: string | null = null;
  cost = 0;

  parse(line: string): HarnessEvent[] {
    let msg: { type?: string; sessionID?: string; part?: Part & { sessionID?: string }; error?: { message?: string } | string };
    try { msg = JSON.parse(line); } catch { return [{ type: 'raw', line }]; }
    const sid = msg.sessionID ?? msg.part?.sessionID;
    if (typeof sid === 'string' && sid) this.sessionId = sid;
    const part = msg.part ?? {};
    if (msg.type === 'error') {
      const m = typeof msg.error === 'string' ? msg.error : msg.error?.message ?? 'opencode error';
      return [{ type: 'error', message: m }];
    }
    switch (part.type) {
      case 'text':
        return part.text ? [{ type: 'assistant_text', text: part.text }] : [];
      case 'tool': {
        const out: HarnessEvent[] = [{ type: 'tool_call', id: String(part.callID ?? randomUUID()), name: String(part.tool ?? 'tool'), input: part.state?.input }];
        const input = (part.state?.input ?? {}) as { filePath?: string };
        if (FILE_TOOLS.has(String(part.tool)) && input.filePath) out.push({ type: 'file_change', path: input.filePath });
        if (part.state?.status === 'completed' || part.state?.status === 'error') out.push({ type: 'tool_result', id: String(part.callID ?? ''), output: part.state.output });
        return out;
      }
      case 'step_finish':
        if (typeof part.cost === 'number') this.cost += part.cost;
        return [];
      case 'step_start':
      case 'reasoning':
      case undefined:
        return [];
      default:
        return [];
    }
  }
}

class OpencodeSession {
  readonly queue = new EventQueue<HarnessEvent>();
  readonly parser = new OpencodeParser();
  private proc: LineProcess | null = null;
  private pending: string[] = [];
  private ending = false;

  constructor(private bin: string, private cwd: string, resumeId: string | undefined) {
    this.parser.sessionId = resumeId ?? null;
  }

  send(text: string): void {
    if (this.proc) { this.pending.push(text); return; }
    this.runTurn(text);
  }

  private runTurn(text: string): void {
    const args = opencodeArgs(this.cwd, this.parser.sessionId, text);
    const p = spawnLines(this.bin, process.platform === 'win32' ? args.map(quoteArg) : args, { cwd: this.cwd });
    this.proc = p;
    void this.pump(p);
  }

  private async pump(p: LineProcess): Promise<void> {
    const pid = p.child.pid;
    if (pid) this.queue.push({ type: 'process_start', pid, pidStartedAt: await processStartTime(pid) });
    for await (const line of p.lines) for (const ev of this.parser.parse(line)) this.queue.push(ev);
    const code = await p.exit;
    this.proc = null;
    if (code !== 0) this.queue.push({ type: 'error', message: `opencode exited with code ${code}` });
    this.queue.push({ type: 'turn_end', nativeSessionId: this.parser.sessionId ?? '', cost: this.parser.cost });
    if (this.ending) { this.queue.close(); return; }
    const next = this.pending.shift();
    if (next !== undefined) this.runTurn(next);
  }

  async end(): Promise<void> {
    this.ending = true;
    this.pending = [];
    if (!this.proc) this.queue.close();
    else await this.proc.exit;
  }

  async interrupt(): Promise<void> {
    const pid = this.proc?.child.pid;
    if (pid) await killProcess(pid);
  }
}

export class OpencodeAdapter implements HarnessAdapter {
  readonly name = 'opencode' as const;
  private sessions = new Map<string, OpencodeSession>();
  constructor(private bin = 'opencode') {}

  start(opts: StartOpts): SessionHandle {
    const id = randomUUID();
    const s = new OpencodeSession(this.bin, opts.cwd, opts.resumeId);
    this.sessions.set(id, s);
    s.send(opts.prompt);
    return { id };
  }
  async send(h: SessionHandle, text: string): Promise<void> { this.get(h).send(text); }
  async interrupt(h: SessionHandle): Promise<void> { await this.get(h).interrupt(); }
  async end(h: SessionHandle): Promise<void> { await this.get(h).end(); this.sessions.delete(h.id); }
  events(h: SessionHandle): AsyncIterable<HarnessEvent> { return this.get(h).queue; }
  private get(h: SessionHandle): OpencodeSession {
    const s = this.sessions.get(h.id);
    if (!s) throw new Error(`opencode session ${h.id} not found`);
    return s;
  }
}

The system prompt file and MCP servers in `StartOpts` are ignored for OpenCode in v1; workers do not need MCP and the orchestrator is always Claude.

import { randomUUID } from 'node:crypto';
import { EventQueue } from '../util/queue';
import { spawnLines, processStartTime, killProcess, quoteArg, type LineProcess } from '../util/procs';
import type { HarnessAdapter, HarnessEvent, SessionHandle, StartOpts } from './types';

export function codexArgs(cwd: string, threadId: string | null, prompt: string): string[] {
  return threadId
    ? ['exec', 'resume', '--json', '--full-auto', '--cd', cwd, threadId, prompt]
    : ['exec', '--json', '--full-auto', '--cd', cwd, prompt];
}

type Item = { id?: string; type?: string; text?: string; command?: string; aggregated_output?: string; exit_code?: number; changes?: { path: string; kind?: string }[]; server?: string; tool?: string; arguments?: unknown; result?: unknown };

export class CodexParser {
  threadId: string | null = null;

  parse(line: string): HarnessEvent[] {
    let msg: { type?: string; thread_id?: string; item?: Item; error?: { message?: string } | string };
    try { msg = JSON.parse(line); } catch { return [{ type: 'raw', line }]; }
    switch (msg.type) {
      case 'thread.started':
        if (typeof msg.thread_id === 'string') this.threadId = msg.thread_id;
        return [];
      case 'turn.started':
      case 'turn.completed':
      case 'item.started':
      case 'item.updated':
        return [];
      case 'turn.failed': {
        const m = typeof msg.error === 'string' ? msg.error : msg.error?.message ?? 'codex turn failed';
        return [{ type: 'error', message: m }];
      }
      case 'error': {
        const m = typeof msg.error === 'string' ? msg.error : msg.error?.message ?? String((msg as { message?: string }).message ?? 'codex error');
        return [{ type: 'error', message: m }];
      }
      case 'item.completed': {
        const it = msg.item ?? {};
        const id = it.id ?? randomUUID();
        switch (it.type) {
          case 'agent_message':
            return it.text ? [{ type: 'assistant_text', text: it.text }] : [];
          case 'command_execution':
            return [
              { type: 'tool_call', id, name: 'command_execution', input: { command: it.command } },
              { type: 'tool_result', id, output: it.aggregated_output },
            ];
          case 'file_change':
            return (it.changes ?? []).map((c) => ({ type: 'file_change', path: c.path }) as HarnessEvent);
          case 'mcp_tool_call':
            return [
              { type: 'tool_call', id, name: `${it.server ?? 'mcp'}.${it.tool ?? 'tool'}`, input: it.arguments },
              { type: 'tool_result', id, output: it.result },
            ];
          default:
            return [];
        }
      }
      default:
        return [{ type: 'raw', line }];
    }
  }
}

class CodexSession {
  readonly queue = new EventQueue<HarnessEvent>();
  readonly parser = new CodexParser();
  private proc: LineProcess | null = null;
  private pending: string[] = [];
  private ending = false;

  constructor(private bin: string, private cwd: string, resumeId: string | undefined) {
    this.parser.threadId = resumeId ?? null;
  }

  send(text: string): void {
    if (this.proc) { this.pending.push(text); return; }
    this.runTurn(text);
  }

  private runTurn(text: string): void {
    const args = codexArgs(this.cwd, this.parser.threadId, text);
    const p = spawnLines(this.bin, process.platform === 'win32' ? args.map(quoteArg) : args, { cwd: this.cwd });
    this.proc = p;
    void this.pump(p);
  }

  private async pump(p: LineProcess): Promise<void> {
    const pid = p.child.pid;
    if (pid) this.queue.push({ type: 'process_start', pid, pidStartedAt: await processStartTime(pid) });
    for await (const line of p.lines) for (const ev of this.parser.parse(line)) this.queue.push(ev);
    const code = await p.exit;
    this.proc = null;
    if (code !== 0) this.queue.push({ type: 'error', message: `codex exited with code ${code}` });
    this.queue.push({ type: 'turn_end', nativeSessionId: this.parser.threadId ?? '' });
    if (this.ending) { this.queue.close(); return; }
    const next = this.pending.shift();
    if (next !== undefined) this.runTurn(next);
  }

  async end(): Promise<void> {
    this.ending = true;
    this.pending = [];
    if (!this.proc) this.queue.close();
    else await this.proc.exit;
  }

  async interrupt(): Promise<void> {
    const pid = this.proc?.child.pid;
    if (pid) await killProcess(pid);
  }
}

export class CodexAdapter implements HarnessAdapter {
  readonly name = 'codex' as const;
  private sessions = new Map<string, CodexSession>();
  constructor(private bin = 'codex') {}

  start(opts: StartOpts): SessionHandle {
    const id = randomUUID();
    const s = new CodexSession(this.bin, opts.cwd, opts.resumeId);
    this.sessions.set(id, s);
    s.send(opts.prompt);
    return { id };
  }
  async send(h: SessionHandle, text: string): Promise<void> { this.get(h).send(text); }
  async interrupt(h: SessionHandle): Promise<void> { await this.get(h).interrupt(); }
  async end(h: SessionHandle): Promise<void> { await this.get(h).end(); this.sessions.delete(h.id); }
  events(h: SessionHandle): AsyncIterable<HarnessEvent> { return this.get(h).queue; }
  private get(h: SessionHandle): CodexSession {
    const s = this.sessions.get(h.id);
    if (!s) throw new Error(`codex session ${h.id} not found`);
    return s;
  }
}

import type { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import type { Bead, HarnessName } from '@overseer/shared';
import type { Db } from '../db/db';
import type { TaskStore } from '../beads/store';
import { columnFor, phaseOf } from '../beads/store';
import type { SessionManager } from '../sessions/manager';
import type { Lifecycle } from '../lifecycle/lifecycle';
import type { Bus } from '../bus';
import { diffAgainstBase } from '../git/git';

export interface McpDeps { db: Db; store: TaskStore; sessions: SessionManager; lifecycle: Lifecycle; bus: Bus }

const ok = (v: unknown) => ({ content: [{ type: 'text' as const, text: JSON.stringify(v, null, 2) }] });
const fail = (e: unknown) => ({ isError: true, content: [{ type: 'text' as const, text: e instanceof Error ? e.message : String(e) }] });
const guard = <A>(fn: (a: A) => Promise<unknown>) => async (a: A) => { try { return ok(await fn(a)); } catch (e) { return fail(e); } };

const harness = z.enum(['claude', 'codex', 'opencode']);
const filter = z.enum(['all', 'ready', 'open', 'in_progress', 'blocked', 'closed', 'review']);

export function registerTools(server: McpServer, d: McpDeps): void {
  const repoOf = (id: string) => {
    const r = d.db.repos.get(id);
    if (!r) throw new Error(`repo ${id} not found; call list_repos`);
    return r;
  };
  const latestSession = (beadId: string) => {
    const rows = d.db.sessions.forBead(beadId);
    const s = rows[rows.length - 1];
    if (!s) throw new Error(`no session for ${beadId}`);
    return s;
  };

  server.tool('list_repos', 'List the repositories Overseer manages.', {}, guard(async () => d.db.repos.all()));

  server.tool('list_tasks', 'List beads in a repo with their board column. filter: all | ready | open | in_progress | blocked | closed | review.', { repo: z.string(), filter: filter.default('all') }, guard(async ({ repo, filter: f }) => {
    const r = repoOf(repo);
    const beads = await d.store.list(r.path);
    const ready = new Set(await d.store.ready(r.path));
    const withCol = beads.map((b) => ({ ...b, column: columnFor(b, ready) }));
    const pick = (b: Bead & { column: string }) => {
      switch (f) {
        case 'all': return true;
        case 'ready': return b.column === 'ready';
        case 'review': return phaseOf(b) === 'review';
        case 'blocked': return b.column === 'blocked';
        default: return b.status === f;
      }
    };
    return withCol.filter(pick);
  }));

  server.tool('bd', 'Run a bd command in a repo and return its JSON output. Overseer adds --json. Example args: ["create","Add login","-d","Use the auth lib","--deps","blocks:ov-3"].', { repo: z.string(), args: z.array(z.string()).min(1) }, guard(async ({ repo, args }) => d.store.raw(repoOf(repo).path, args)));

  server.tool('spawn_worker', 'Dispatch a headless worker for a bead in its own worktree. Optional instructions are appended to the worker prompt (use them after a rejection or merge conflict).', { repo: z.string(), bead_id: z.string(), harness, instructions: z.string().optional() }, guard(async ({ repo, bead_id, harness: h, instructions }) => {
    const id = await d.lifecycle.spawnWorker(repo, bead_id, h as HarnessName, instructions);
    return { session_id: id, bead_id, harness: h };
  }));

  server.tool('message_worker', 'Send a follow-up message to the running worker of a bead.', { repo: z.string(), bead_id: z.string(), text: z.string().min(1) }, guard(async ({ repo, bead_id, text }) => {
    repoOf(repo);
    const s = latestSession(bead_id);
    if (s.status !== 'running') throw new Error(`worker for ${bead_id} is not running (status ${s.status})`);
    await d.sessions.send(s.id, text);
    return { delivered: true, session_id: s.id };
  }));

  server.tool('interrupt_worker', 'Kill the running worker of a bead. The session-end rule then applies: commits → verify → review, no commits → failed and bead reopened.', { repo: z.string(), bead_id: z.string() }, guard(async ({ repo, bead_id }) => {
    repoOf(repo);
    const s = latestSession(bead_id);
    if (s.status !== 'running') throw new Error(`worker for ${bead_id} is not running`);
    await d.sessions.interrupt(s.id);
    return { interrupted: true, session_id: s.id };
  }));

  server.tool('worker_status', 'State, last assistant text, changed files and cost for the latest worker session of a bead.', { repo: z.string(), bead_id: z.string() }, guard(async ({ repo, bead_id }) => {
    repoOf(repo);
    const s = latestSession(bead_id);
    const st = d.sessions.status(s.id);
    const wt = d.db.worktrees.get(bead_id);
    return { session_id: s.id, harness: s.harness, state: st.state, last_text: st.lastText, files: st.files, cost: st.cost, verify_status: wt?.verify_status ?? null, started_at: s.started_at, ended_at: s.ended_at };
  }));

  server.tool('worker_diff', 'Unified diff of the bead branch against the repo base branch.', { repo: z.string(), bead_id: z.string() }, guard(async ({ repo, bead_id }) => {
    const r = repoOf(repo);
    const wt = d.db.worktrees.get(bead_id);
    if (!wt) throw new Error(`no worktree for ${bead_id}`);
    return await diffAgainstBase(wt.path, r.base_branch);
  }));

  server.tool('request_merge', 'Mark a verified task as ready for the user to merge, with a note that becomes the review summary and MR description.', { repo: z.string(), bead_id: z.string(), note: z.string().min(1) }, guard(async ({ repo, bead_id, note }) => {
    await d.lifecycle.requestMerge(repo, bead_id, note);
    return { queued_for_review: true, bead_id };
  }));

  server.tool('ask_user', 'Ask the user a question in the chat. Returns immediately with the question id; the answer arrives as a later user message prefixed with "Answer to question #<id>". End your turn after asking.', { question: z.string().min(1) }, guard(async ({ question }) => {
    const row = d.db.chat.insert({ role: 'assistant', kind: 'question', text: question });
    d.bus.emit('chat');
    return { question_id: row.id };
  }));
}

import type { FastifyInstance } from 'fastify';
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StreamableHTTPServerTransport } from '@modelcontextprotocol/sdk/server/streamableHttp.js';
import { registerTools, type McpDeps } from './tools';

export async function registerMcp(app: FastifyInstance, deps: McpDeps): Promise<void> {
  app.removeContentTypeParser('application/json');
  app.addContentTypeParser('application/json', { parseAs: 'string' }, (_req, body, done) => {
    try { done(null, body.length ? JSON.parse(body as string) : undefined); } catch (e) { done(e as Error); }
  });
  app.route({
    method: ['GET', 'POST', 'DELETE'],
    url: '/mcp',
    handler: async (req, reply) => {
      const server = new McpServer({ name: 'overseer', version: '0.1.0' });
      registerTools(server, deps);
      const transport = new StreamableHTTPServerTransport({ sessionIdGenerator: undefined });
      reply.hijack();
      reply.raw.on('close', () => { void transport.close(); void server.close(); });
      await server.connect(transport);
      await transport.handleRequest(req.raw, reply.raw, req.body);
    },
  });
}
```

Stateless mode: a fresh `McpServer` + transport per request, which the SDK documents as the simplest Streamable HTTP setup and avoids session bookkeeping. The custom JSON parser keeps Fastify's body parsing but makes an empty body parse to `undefined` for GET/DELETE.

If `registerMcp` is later registered on the same Fastify instance as the REST routes (Task 13), the content-type parser replacement is global and harmless: REST handlers still receive parsed JSON.

You are the Overseer orchestrator. You run as one long-lived session and talk to a single user through a chat panel. You never edit code yourself: you break work into beads tasks and dispatch headless workers that do the coding in isolated git worktrees.

## Tools (MCP server "overseer")

- `list_repos` — the repositories you manage. Every other tool takes a `repo` id from here.
- `list_tasks(repo, filter)` — beads with their board column (ready, blocked, running, verifying, review, done).

- `request_merge(repo, bead_id, note)` — after the worker's verification passed, hand the task to the user for review. The note is the review summary and the merge-request description: say what changed and why.
- `ask_user(question)` — ask the user something. It returns immediately with a question id. End your turn after asking; the answer arrives later as a message starting with `Answer to question #<id>`.

## How to work

1. When the user asks for something, look at the repo with `list_tasks` first, then create small, independently mergeable beads with clear descriptions and `blocks:` dependencies.
2. Dispatch ready beads with `spawn_worker`. Prefer `claude` unless the user asks for another harness.
3. When a worker finishes, Overseer verifies the branch and moves the task to review, or reopens it if the worker produced no commits. Messages starting with `[Overseer]` are system notices about these transitions and about merge conflicts.
4. Check `worker_status` and `worker_diff` before `request_merge`. If the diff is wrong, `interrupt_worker` or send a `message_worker`, or reject by re-dispatching with instructions.
5. The user merges or rejects in the Review view. A rejected task comes back as ready with a `Rejected:` note; re-dispatch it with `instructions` that address the note.
6. Keep chat replies short. Report what you did and what you are waiting on.

Messages prefixed `[repo: <id>]` tell you which repository the user is talking about.

import fs from 'node:fs';
import path from 'node:path';
import type { StatusResponse } from '@overseer/shared';
import type { Db } from '../db/db';
import type { Bus } from '../bus';
import type { Config } from '../config';
import type { SessionManager } from '../sessions/manager';

export interface OrchestratorDeps { db: Db; sessions: SessionManager; bus: Bus; config: Config }

export class Orchestrator {
  private sessionId: string | null = null;

  constructor(private d: OrchestratorDeps) {
    d.bus.on('event', (e) => {
      if (e.session_id !== this.sessionId || e.type !== 'assistant_text') return;
      const text = (e.payload as { text?: string }).text;
      if (!text) return;
      d.db.chat.insert({ role: 'assistant', kind: 'message', text });
      d.bus.emit('chat');
    });
    d.bus.on('session:ended', (e) => { if (e.session.id === this.sessionId) d.bus.emit('status'); });
  }

  status(): StatusResponse['orchestrator'] {
    const row = this.sessionId ? this.d.db.sessions.get(this.sessionId) : this.d.db.sessions.latest('orchestrator');
    if (!row) return { status: 'idle', native_session_id: null };
    return { status: row.status, native_session_id: row.native_session_id };
  }

  async sendUser(text: string): Promise<void> {
    this.d.db.chat.insert({ role: 'user', kind: 'message', text });
    this.d.bus.emit('chat');
    await this.deliver(text);
  }

  async answer(questionId: number, text: string): Promise<void> {
    const q = this.d.db.chat.get(questionId);
    if (!q || q.kind !== 'question') throw new Error(`question ${questionId} not found`);
    this.d.db.chat.answer(questionId, text);
    this.d.bus.emit('chat');
    await this.deliver(`Answer to question #${questionId} ("${q.text}"): ${text}`);
  }

  async systemMessage(text: string): Promise<void> {
    this.d.db.chat.insert({ role: 'system', kind: 'message', text });
    this.d.bus.emit('chat');
    if (this.sessionId && this.d.sessions.isLive(this.sessionId)) await this.deliver(`[Overseer] ${text}`);
  }

  private async deliver(text: string): Promise<void> {
    if (this.sessionId && this.d.sessions.isLive(this.sessionId)) {
      await this.d.sessions.send(this.sessionId, text);
      return;
    }
    const { config, db, sessions } = this.d;
    fs.mkdirSync(config.orchestratorDir, { recursive: true });
    const previous = db.sessions.latest('orchestrator');
    const row = sessions.start({
      role: 'orchestrator',
      harness: 'claude',
      cwd: config.orchestratorDir,
      prompt: text,
      systemPromptFile: path.join(config.promptsDir, 'orchestrator.md'),
      mcpServers: [{ name: 'overseer', url: `http://127.0.0.1:${config.port}/mcp` }],
      resumeId: previous?.native_session_id ?? undefined,
      keepAlive: true,
    });
    this.sessionId = row.id;
    this.d.bus.emit('status');
  }
}
```

A system message while no orchestrator session is live is only recorded in chat; starting a session just to deliver a notice would burn tokens with nobody asking. The next user message starts the session and the orchestrator can read the board with `list_tasks`.

import type { BoardCard, BoardResponse, HarnessName, Repo } from '@overseer/shared';
import type { Db } from '../db/db';
import { columnFor, HARNESS_PREFIX, type TaskStore } from '../beads/store';

const HARNESSES: HarnessName[] = ['claude', 'codex', 'opencode'];

export async function buildBoard(db: Db, store: TaskStore): Promise<BoardResponse> {
  const bd_ok = await store.available();
  const repos: BoardResponse['repos'] = [];
  for (const repo of db.repos.all()) {
    repos.push({ repo, cards: bd_ok ? await cardsFor(db, store, repo) : [] });
  }
  return { bd_ok, repos };
}

async function cardsFor(db: Db, store: TaskStore, repo: Repo): Promise<BoardCard[]> {
  const beads = await store.list(repo.path);
  const ready = new Set(await store.ready(repo.path));
  const now = Date.now();
  return beads.map((bead) => {
    const sessions = db.sessions.forBead(bead.id);
    const s = sessions[sessions.length - 1];
    const labelHarness = bead.labels.find((l) => l.startsWith(HARNESS_PREFIX))?.slice(HARNESS_PREFIX.length);
    const harness = (HARNESSES as string[]).includes(labelHarness ?? '') ? (labelHarness as HarnessName) : s?.harness ?? null;
    const wt = db.worktrees.get(bead.id);
    const elapsed = s ? (s.ended_at ? Date.parse(s.ended_at) : now) - Date.parse(s.started_at) : null;
    return { bead, repo_id: repo.id, column: columnFor(bead, ready), harness, branch: wt?.branch ?? null, cost: s?.cost ?? null, elapsed_ms: elapsed, session_status: s?.status ?? null };
  });
}

import type { FastifyInstance } from 'fastify';
import websocket from '@fastify/websocket';
import type { WsMessage } from '@overseer/shared';
import type { Bus } from '../bus';

export async function registerWs(app: FastifyInstance, bus: Bus): Promise<void> {
  await app.register(websocket);
  const clients = new Set<{ send(data: string): void; readyState: number }>();
  const broadcast = (m: WsMessage) => {
    const data = JSON.stringify(m);
    for (const c of clients) if (c.readyState === 1) c.send(data);
  };
  bus.on('event', (event) => broadcast({ type: 'event', event }));
  bus.on('board', () => broadcast({ type: 'board' }));
  bus.on('chat', () => broadcast({ type: 'chat' }));
  bus.on('status', () => broadcast({ type: 'status' }));
  app.get('/api/events', { websocket: true }, (socket) => {
    clients.add(socket);
    socket.on('close', () => clients.delete(socket));
  });
}

import type { Config } from '../config';
import { runCapture } from '../util/procs';
import { pushBranch } from './git';

export type GlabRunner = (cwd: string, args: string[]) => Promise<{ code: number; stdout: string; stderr: string }>;

export class GitlabMrProvider implements GitProvider {
  constructor(private glab: GlabRunner) {}

  async land(repo: Repo, wt: WorktreeRow, mr: { title: string; description: string }): Promise<LandResult> {
    await pushBranch(wt.path, wt.branch);
    const r = await this.glab(repo.path, ['mr', 'create', '--source-branch', wt.branch, '--target-branch', repo.base_branch, '--title', mr.title, '--description', mr.description, '--yes']);
    if (r.code !== 0) throw new Error(`glab mr create failed (exit ${r.code}): ${r.stderr.trim() || r.stdout.trim()}`);
    const url = r.stdout.match(/https?:\/\/\S+/)?.[0];
    return { ok: true, mrUrl: url };
  }
}

export function providerFor(repo: Repo, config: Config): GitProvider {
  return repo.merge_mode === 'gitlab-mr'
    ? new GitlabMrProvider((cwd, args) => runCapture(config.glabBin, args, { cwd }))
    : new LocalMergeProvider();
}

import { useEffect, useRef } from 'react';
import type { WsMessage } from '@overseer/shared';

export class ApiError extends Error {
  constructor(readonly status: number, message: string, readonly body: unknown) { super(message); }
}

async function request<T>(method: 'GET' | 'POST', path: string, body?: unknown): Promise<T> {
  const res = await fetch(`/api${path}`, { method, headers: body === undefined ? {} : { 'content-type': 'application/json' }, body: body === undefined ? undefined : JSON.stringify(body) });
  const text = await res.text();
  const data = text ? JSON.parse(text) : null;
  if (!res.ok) throw new ApiError(res.status, (data as { error?: string } | null)?.error ?? `${method} ${path} failed with ${res.status}`, data);
  return data as T;
}

export const api = {
  get: <T>(path: string) => request<T>('GET', path),
  post: <T>(path: string, body?: unknown) => request<T>('POST', path, body),
};

export function useWs(onMessage: (m: WsMessage) => void): void {
  const handler = useRef(onMessage);
  handler.current = onMessage;
  useEffect(() => {
    let socket: WebSocket | null = null;
    let timer: ReturnType<typeof setTimeout> | null = null;
    let stopped = false;
    const connect = () => {
      const proto = location.protocol === 'https:' ? 'wss' : 'ws';
      socket = new WebSocket(`${proto}://${location.host}/api/events`);
      socket.onmessage = (e) => { try { handler.current(JSON.parse(String(e.data)) as WsMessage); } catch { /* ignore malformed */ } };
      socket.onclose = () => { if (!stopped) timer = setTimeout(connect, 1000); };
    };
    connect();
    return () => { stopped = true; if (timer) clearTimeout(timer); socket?.close(); };
  }, []);
}

export function fmtElapsed(ms: number | null): string {
  if (ms === null) return '';
  const s = Math.floor(ms / 1000);
  if (s < 60) return `${s}s`;
  const m = Math.floor(s / 60);
  return m < 60 ? `${m}m ${s % 60}s` : `${Math.floor(m / 60)}h ${m % 60}m`;
}

export function fmtCost(c: number | null): string { return c === null ? '' : `$${c.toFixed(2)}`; }

const COLUMNS: { key: BoardColumn; label: string }[] = [

export interface DiffFile { file: string; body: string }

export function splitDiff(diff: string): DiffFile[] {
  if (!diff.trim()) return [];
  const parts = diff.split(/^(?=diff --git )/m).filter((p) => p.trim());
  return parts.map((p) => {
    const m = p.match(/^diff --git a\/(\S+) b\/(\S+)/);
    return { file: m?.[2] ?? m?.[1] ?? '(unknown)', body: p };
  });
}

function lineClass(l: string): string {
  if (l.startsWith('+++') || l.startsWith('---')) return 'diff-meta';
  if (l.startsWith('@@')) return 'diff-hunk';
  if (l.startsWith('+')) return 'diff-add';
  if (l.startsWith('-')) return 'diff-del';
  return '';
}

export function Diff(p: { diff: string | null }) {
  const files = splitDiff(p.diff ?? '');
  if (files.length === 0) return <p className="muted">No changes against the base branch.</p>;
  return (
    <div className="diff">
      {files.map((f) => (
        <details key={f.file} open>
          <summary>{f.file}</summary>
          <pre>{f.body.split('\n').map((l, i) => <div key={i} className={lineClass(l)}>{l}</div>)}</pre>
        </details>
      ))}
    </div>
  );
}

import { useEffect, useState } from 'react';
import type { BoardCard, BoardResponse, TaskDetail } from '@overseer/shared';
import { api, ApiError } from '../api';
import { Diff } from '../components/Diff';

export function Review(p: { version: number; selected: string | null; onSelect: (id: string | null) => void }) {
  const [cards, setCards] = useState<BoardCard[]>([]);
  const [detail, setDetail] = useState<TaskDetail | null>(null);
  const [note, setNote] = useState('');
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  useEffect(() => {
    void api.get<BoardResponse>('/board').then((b) => {
      const inReview = b.repos.flatMap((r) => r.cards).filter((c) => c.column === 'review');
      setCards(inReview);
      if (!p.selected && inReview[0]) p.onSelect(inReview[0].bead.id);
    });
  }, [p.version]);
  useEffect(() => {
    if (!p.selected) { setDetail(null); return; }
    void api.get<TaskDetail>(`/tasks/${p.selected}`).then(setDetail).catch(() => setDetail(null));
  }, [p.selected, p.version]);

  const act = async (fn: () => Promise<unknown>) => {
    setBusy(true); setError(null);
    try { await fn(); } catch (e) { setError(e instanceof ApiError ? e.message : String(e)); } finally { setBusy(false); }
  };
  const merge = () => act(async () => { await api.post(`/tasks/${p.selected}/merge`); p.onSelect(null); });
  const reject = () => { if (!note.trim()) { setError('A rejection note is required.'); return; } void act(async () => { await api.post(`/tasks/${p.selected}/reject`, { note: note.trim() }); setNote(''); p.onSelect(null); }); };

  const wt = detail?.worktree;
  return (
    <div className="review-layout">
      <ul className="review-list">
        {cards.length === 0 && <li className="muted">No tasks in review.</li>}
        {cards.map((c) => <li key={c.bead.id} className={c.bead.id === p.selected ? 'active' : ''} onClick={() => p.onSelect(c.bead.id)}>{c.bead.title}</li>)}
      </ul>
      {detail && (
        <div className="review-detail">
          <h2>{detail.bead.title} <span className="muted">{detail.bead.id} · {wt?.branch}</span></h2>
          <h4>Verification: {wt?.verify_status ?? 'not run'}</h4>
          {wt?.verify_output && <pre>{wt.verify_output}</pre>}
          <h4>Orchestrator note</h4>
          <p className="pre">{wt?.review_note ?? 'No note yet: the orchestrator has not called request_merge. The bead title and description will be used as the merge description.'}</p>
          {wt?.conflict_files && wt.conflict_files.length > 0 && (
            <div className="banner-warn">Last merge conflicted in: {wt.conflict_files.join(', ')}</div>
          )}
          <div className="review-actions">
            <button disabled={busy} onClick={() => void merge()}>Merge</button>
            <input value={note} placeholder="Why? (required to reject)" onChange={(e) => setNote(e.target.value)} />
            <button disabled={busy} onClick={reject}>Reject</button>
          </div>
          {error && <div className="badge-warn">{error}</div>}
          <h4>Diff against {wt?.base_branch}</h4>
          <Diff diff={detail.diff} />
        </div>
      )}
    </div>
  );
}
